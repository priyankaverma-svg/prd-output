What it Is
Buyers can repurchase a past order with one click from Order History, the dashboard orders tab, and order confirmation pages.

Why it Matters
Repeat buyers previously had to rebuild carts from scratch, adding friction to a high-intent repeat-purchase flow.

Key Benefits
Faster repeat sourcing for buyers who order the same parts regularly. A/B test showed +49% clicks and +37% orders (per provided analysis).

NSMs Impacted
Buyer bookings, repeat order rate
